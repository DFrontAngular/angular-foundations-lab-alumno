# Capstone · Product Workspace

**Duración orientativa:** 16–24 horas

Construye una aplicación de catálogo sobre la API local del repositorio.

## Alcance obligatorio

- Shell y navegación accesibles.
- Listado remoto paginado.
- Búsqueda, categoría y orden sincronizados con query params.
- Detalle lazy por ID.
- Alta y edición con una de las dos APIs de formularios.
- Documento breve justificando por qué has elegido Reactive Forms o Signal Forms.
- Borrado con confirmación accesible.
- Favoritos persistidos localmente.
- Estados loading, error, vacío y success.
- Lecturas con `httpResource` y mutaciones con `HttpClient`.
- Store de feature con provider de ruta.
- Tests de los flujos críticos desde la UI.
- Responsive desde 320 px y navegación por teclado.

## Fuera de alcance

No añadas login, refresh token, roles, NgRx, SSR, una tabla genérica ni un design system. Esas variables pertenecen a una práctica posterior.
