# Diagnóstico Angular · 90 minutos

## Propósito

No se utiliza para aprobar o suspender. Sirve para identificar el punto de entrada y el nivel de acompañamiento.

## Enunciado

Sobre el starter, construye una pequeña feature que:

1. represente una lista local de productos;
2. filtre por nombre mediante un signal y un `computed()`;
3. extraiga una tarjeta con input requerido y output;
4. marque productos favoritos;
5. navegue a un detalle con parámetro de ruta;
6. represente estado vacío;
7. incluya una prueba de interacción desde el DOM.

No es obligatorio terminar. La persona puede consultar documentación y utilizar IA si declara cómo la ha empleado y puede explicar o modificar el resultado.

## Restricciones

- No manipular el DOM directamente.
- No introducir Zone.js.
- No instalar una librería de estado o UI.
- No usar `any` para resolver errores de tipado.
- Mantener accesibilidad básica y foco visible.
