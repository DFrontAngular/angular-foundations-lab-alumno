# 03 · Control flow y listas

**Tiempo orientativo:** 75–105 minutos

## Tarea

Implementa un catálogo local con búsqueda y filtro por estado.

- Usa `@for` con una identidad estable.
- Representa el estado vacío con `@empty`.
- Usa `@switch` para la etiqueta de estado.
- Normaliza la búsqueda ignorando mayúsculas y espacios extremos.
- No filtres directamente desde el template.

## Prueba

```bash
npm run test:exercise -- 03
```
