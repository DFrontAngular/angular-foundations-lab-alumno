# 02 · Signals y estado derivado

**Tiempo orientativo:** 75–105 minutos

## Objetivo

Distinguir entre estado fuente y valores que deben calcularse.

## Tarea

Completa una cesta para que permita modificar cantidades y calcule subtotal, IVA y total.

## Reglas

- La cantidad mínima de cada línea es `0`.
- No mutar objetos ni arrays existentes.
- `subtotal`, `tax` y `total` deben ser `computed()`.
- El IVA es el 21 %.
- Una línea con cantidad `0` sigue visible para poder recuperarla.

## Prueba

```bash
npm run test:exercise -- 02
```
