# 11 · Mutaciones con HttpClient

**Tiempo orientativo:** 2–3 horas

## Tarea

Implementa alta y borrado de productos.

- Las lecturas continúan usando `httpResource`.
- `POST` y `DELETE` se ejecutan con `HttpClient`.
- Una operación activa deshabilita acciones incompatibles.
- El éxito recarga el recurso.
- Los errores dejan la interfaz recuperable y muestran feedback.
- No mantengas suscripciones manuales vivas en el componente.

## Prueba

```bash
npm run test:exercise -- 11
```
