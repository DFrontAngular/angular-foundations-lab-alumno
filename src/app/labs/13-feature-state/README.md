# 13 · Estado de feature

**Tiempo orientativo:** 2–3 horas

## Tarea

Completa un store local de catálogo.

- Signals mutables privados.
- Lecturas públicas readonly.
- Valores derivados con `computed()`.
- Acciones explícitas para modificar favoritos y filtro.
- Provider en la ruta para limitar la vida del estado a la feature.
- Sin un servicio global que acumule responsabilidades ajenas.

## Prueba

```bash
npm run test:exercise -- 13
```
