# 06 · Pipes y directivas

**Tiempo orientativo:** 90–120 minutos

## Tarea

Completa dos piezas reutilizables:

1. un pipe puro que convierta stock en una etiqueta de negocio;
2. una directiva que añada la clase `search-match` cuando un texto contiene la búsqueda.

## Reglas

- `0`: «Agotado».
- `1–5`: «Últimas unidades».
- Más de `5`: «Disponible».
- La comparación de búsqueda ignora mayúsculas y espacios extremos.
- La directiva no debe escribir `innerHTML`.

## Prueba

```bash
npm run test:exercise -- 06
```
