# Política de uso de IA

La IA está permitida porque forma parte del trabajo real, pero no sustituye la comprensión.

## Obligaciones

- Declarar qué herramienta se usó y para qué.
- Revisar cada cambio antes de incorporarlo.
- Poder explicar tipos, flujo de datos, dependencias y tests.
- Poder modificar la solución durante la revisión.
- No compartir secretos, código privado ni datos personales.

## Uso adecuado

- Pedir alternativas y tradeoffs.
- Generar casos de prueba que después se revisan.
- Interpretar un error concreto.
- Reducir boilerplate conocido.
- Revisar accesibilidad o consistencia.

## Uso insuficiente

- Copiar una feature completa sin comprenderla.
- Aceptar casts o `any` para silenciar el compilador.
- Pedir a la IA que justifique decisiones tomadas después del código.
- Presentar tests que nunca se han ejecutado.

La evaluación se basa en comportamiento y explicación, no en autoría manual de cada carácter.
