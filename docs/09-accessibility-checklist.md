# Checklist de accesibilidad

- [ ] Existe un único `h1` coherente por página.
- [ ] Los controles tienen label accesible.
- [ ] Enlaces navegan y botones ejecutan acciones.
- [ ] Todo es operable con teclado.
- [ ] El foco visible no se elimina.
- [ ] Los mensajes de error están asociados al campo.
- [ ] Loading y feedback usan `role=status` o regiones live cuando corresponde.
- [ ] Errores recuperables usan `role=alert` con moderación.
- [ ] `aria-expanded`, `aria-pressed` y `aria-invalid` reflejan el estado real.
- [ ] No se comunica información solo mediante color.
- [ ] La interfaz funciona a 320 px.
- [ ] El movimiento respeta `prefers-reduced-motion`.
