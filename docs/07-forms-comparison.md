# Reactive Forms y Signal Forms

El laboratorio 09 evita comparar ejemplos distintos. Ambas variantes implementan exactamente el mismo formulario y pasan el mismo contrato de UI.

## Criterio de elección

No elijas por novedad ni por cantidad de líneas. Considera:

- versión Angular objetivo;
- experiencia del equipo;
- formularios existentes;
- componentes de control propios;
- complejidad de validación;
- interoperabilidad con librerías;
- estrategia de migración y soporte.

En este repositorio Signal Forms corresponde a Angular 22 y se usa como API estable. Reactive Forms sigue siendo una API válida y ampliamente implantada.
