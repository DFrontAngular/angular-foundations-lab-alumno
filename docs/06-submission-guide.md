# Guía de entrega

## Por laboratorio

Incluye:

- código;
- tests ejecutados;
- breve nota de decisiones;
- limitaciones conocidas;
- declaración de uso de IA.

## Pull request

Usa la plantilla incluida y mantén cada PR centrada en un laboratorio. Evita mezclar refactors globales con la resolución del ejercicio.

## Capstone

Añade:

- README de arranque;
- diagrama simple de responsabilidades;
- decisión de API de formularios;
- lista de flujos probados;
- deuda técnica consciente;
- capturas opcionales, nunca como sustituto de una demo.

## Comandos mínimos

```bash
npm run check
npm run build
npm test
npm run test:exercise -- <id>
```
